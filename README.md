# Линейка

Расширение Chrome. Боковая панель, как у чата: локальная мини-модель, калькулятор, конспекты 1–11 класса и курсор, который сам доезжает до поля на странице и печатает ответ.

Облако не нужно. Учебники здесь — короткие конспекты программы, не сканы книг.

## Установить

1. Скачай этот репозиторий и распакуй, либо склонируй его.
2. Собери расширение (см. «Сборка» ниже). Папка `dist` в репозиторий не входит, её создаёт сборка.
3. Открой `chrome://extensions`.
4. Включи «Режим разработчика».
5. «Загрузить распакованное» и выбери папку `dist`.
6. Нажми на иконку линейки. Справа откроется панель.

Нужен Chrome 114 или новее. Папка для загрузки — именно `dist`, не корень репозитория.

## Как решать страницу

1. Открой обычный сайт с полями для ответов (не `chrome://` и не пустую новую вкладку).
2. В панели вкладка «Курсор» → «Снимок».
3. «Заполнить пустые» — курсор едет только к пустым полям, рядом с которыми виден текст задачи.
4. Либо реши во вкладке «Чат» / «Счёт» и нажми «Вписать курсором» в выбранное поле.

Курсор — слой поверх страницы. Он не двигает системную мышь и не обходит пароли, почту и скрытые поля.

## Сборка

Нужен Node.js 18 или новее.

```bash
npm install
npm run build        # собирает dist/
npm run typecheck    # проверка типов TypeScript
npm run selftest     # самопроверка решателя (engine.ts)
```

После пересборки на `chrome://extensions` нажми обновить у Линейки.

## Модель (Ollama)

Для условий, которые правила не распознают, вкладка «Решить» умеет спросить локальную модель через [Ollama](https://ollama.com/download). Модель работает на твоём компьютере, задача никуда не уходит.

1. Скачай и установи Ollama: https://ollama.com/download
2. В терминале скачай модель: `ollama pull qwen2.5:3b` (или другую из библиотеки Ollama, она пишется в блоке «Модель» на вкладке «Решить»).
3. Если панель пишет, что Ollama не отвечает, запусти её с разрешением для расширения: `OLLAMA_ORIGINS=chrome-extension://*` (в Windows — через переменные среды).
4. На вкладке «Решить» введи задачу и нажми «Спросить модель».

Честно про качество: маленькая модель на 3B решает простые текстовые задачи и часто ошибается в сложных. Ответ с шагами проверяй сам. Учебники в проект не входят: конспекты написаны по общей программе, а модель опирается только на то, что ты написал в задаче.

## Конспекты

Конспекты лежат в `src/lessons/grade1.ts` … `grade11.ts`, сборка в `src/curriculum.ts`. Всего 135 записей по основным предметам (математика, русский, окружающий мир, биология, география, история, алгебра, геометрия, физика, химия, обществознание). Записи написаны по общей школьной программе, не по конкретному учебнику: сверяй с тем, по чему учится класс.

Новая запись делается функцией `make(...)` из `src/lessons/make.ts`. Ключевые слова (`keys`) пиши в нижнем регистре — по ним ищется тема. Слова короче трёх букв поиск не учитывает.
