# Прототип: вид от третьего лица

Трёхмерный мир из блоков (three.js), камера за спиной героя, пиксельные персонажи-спрайты 24×32 из набора Svetlana Kushnariova (CC-BY 3.0, см. assets/game/chars2/LICENSE.md). Спрайты всегда повёрнуты к камере; берётся первый кадр, анимации ходьбы пока нет. Логика улик, дневника, рыбки и концовок та же, что в боковом прототипе (`../game`).

## Запуск

```bash
npm install
npm run build      # собирает dist/
npm run typecheck
```

Открыть `dist/index.html` через локальный сервер, например `python3 -m http.server 8000` в папке `dist`.

## Управление

- WASD — ходить относительно камеры, пробел — прыжок
- ← → — поворот камеры
- ЛКМ — копать блок, ПКМ — поставить землю
- E — говорить с ближайшим жителем, F — рыбка
- Z — записать улику, Tab — дневник, пробел — дальше по тексту
