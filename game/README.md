# Прототип игры

Браузерная 2D-песочница с тайлами. Первая версия: пролог, одна деревня, улики, дневник, рыбка-поддержка, ложная цель (чудовище в руинах) и концовки. Графика — пиксельная, рисуется кодом (без внешних картинок): текстуры блоков с травой, стенами пещер и досками, небо и два слоя холмов, персонажи-спрайты, вечернее затемнение.

## Запуск

```bash
npm install
npm run build       # собирает dist/
npm run typecheck   # проверка типов
```

Открыть `dist/index.html` через локальный сервер, например `python3 -m http.server 8000` в папке `dist`.

## Управление

- A / D — ходить, W — прыжок
- ЛКМ — копать блок, ПКМ — поставить землю (нужна земля из раскопок)
- E — подойти и поговорить с жителем (реплика уже готова, текста не вводится)
- F — рыбка-поддержка (реплика зависит от дня)
- Z — записать улику в дневник, когда она появилась (тёмный экран на 2 секунды)
- Tab — открыть дневник
- Пробел — дальше по тексту

## Что реализовано

- Пролог: три карточки о детстве и предательстве друга.
- Деревня: генерация мира по seed, копание и постройка, дома, руины на востоке.
- Жители: три специалиста (Савва, Игорь, Нина) и Артём. Внимание к специалисту растёт при разговорах; на четвёртом разговоре он уходит, на карте остаётся метка «(ушёл)».
- Друг: на 3-й, 5-й и 7-й встрече появляются улики в поведении. На 7-й встрече ночью приходит месть (концовка «revenge»).
- Дневник: улика появляется на короткое время. Если не записать, она пропадает и идёт в счёт пропущенных. Два пропуска за день — город настроен против героя, ночью вне дома — концовка «caught».
- Рыбка: восемь заранее написанных реплик по ключу (напряжён ли город, есть ли записи, близок ли друг).
- Ложная цель: чудовище в руинах, восемь ударов. После победы — концовка «break» с сообщением «будем дорабатывать игру».

## Что сознательно не сделано в прототипе

- Звук и анимации (спрайты статичные, без ходьбы и кадров).
- Баланс: длина дня (75 секунд), пороги и число улик не проверены на игроке.
- Сохранения: состояние сбрасывается при каждом запуске.
- Возврат ушедших жителей и сложный бой с другом: месть пока сразу заканчивает игру.
- Рыбка: только восемь реплик, их нужно проверить по тексту и тону.
- Имена (Савва, Игорь, Нина, Артём) — заглушки.

## Проверки

Прогон в Chromium (через имитацию в скрипте): пролог переходит в деревню, три встречи с другом дают улику, Z записывает её в дневник, рыбка показывает реплику, четыре встречи с ювелиром уводят его, руины порождают чудовище. Ошибок в консоли нет, кроме 404 на иконку страницы.
